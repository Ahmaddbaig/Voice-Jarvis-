## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| search_web -> SearXNG | Localhost HTTP to Docker container; SearXNG returns JSON with URLs |
| URL set -> fetch_page | Per-turn URL set is the trust gate for outbound fetches |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Spoofing | search.py URL set | mitigate | `_current_turn_urls` is a private module-level set; only `search_web` populates it; `clear_turn_urls()` resets at turn start |
| T-08-02 | Tampering | SearXNG results | accept | SearXNG runs on localhost; no network exposure. Result URLs are data, not commands. |
| T-08-03 | Denial of Service | SearXNG container | mitigate | `restart: unless-stopped` in docker-compose; 10s timeout in search_web; graceful degradation message on failure |
</threat_model>
